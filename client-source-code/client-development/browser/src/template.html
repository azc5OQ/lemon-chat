Lemon Chat uses only the DataChannel part of the WebRTC stack. It works like a WebSocket over UDP. The server acts as the other WebRTC peer, so users do not connect directly to each other or share their IP addresses through WebRTC. With either connection, the server relays your encrypted audio without having the keys to decrypt it. Both WebRTC DataChannel and WebSocket are available as an experiment to see which works better for audio.

Import Identity

An identity file (.lmn) contains a complete identity. Importing it makes this device connect as that identity, and any server that already knows it restores the associated tags and permissions. Select the file or drop it onto this dialog; nothing changes until you confirm. Rebuilding the key pair can take a moment. The file is read locally and never leaves this device.

Export Identity

This identity is the RSA key pair this device connects with; tags and permissions granted on a server are bound to it. Export it as a file to keep a backup or to move it to another device, where it can be imported. Treat the file and the passphrase below as secrets: anyone who holds them can act as you.
