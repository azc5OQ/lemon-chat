Identity

An identity file (.lmn) holds an identity. Import one and this device connects as that identity - the server recognizes it and restores its tags and permissions. Pick the file (or drop it here); nothing happens until you confirm. Re-creating the keypair may take a moment. The file never leaves your device.

Your Identity

Your identity is the RSA keypair this device connects with - tags and permissions on a server are tied to it. Save it as a file to keep it, or to carry it to another device (import it there). Never share the file or the passphrase below: whoever has it becomes you.
